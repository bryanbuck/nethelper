● Login Flow from Frontend Perspective

  Here's how the login flow works in your Vue.js frontend:

  1. User Access Flow

  - User visits protected route (e.g., /dashboard) → router guard redirects to /login?redirect=/dashboard
  - User directly visits /login

  2. Login Form (LoginView.vue:153-168)

  - User enters email/password with VeeValidate validation
  - Form submission calls authStore.login() with credentials
  - Loading state prevents multiple submissions

  3. Authentication Store Process (auth.js:20-47)

  - authStore.login() calls authService.login()
  - On success:
    - Stores access_token, refresh_token, and user data
    - Persists tokens to localStorage
    - Redirects to intended page or /dashboard
  - On failure:
    - Sets error message displayed in login form

  4. API Service Layer (auth.service.js:11-16)

  - Makes POST request to /auth/login with email/password
  - Returns JWT tokens and user profile from backend

  5. Route Protection (router/index.js:175-218)

  - beforeEach guard checks requiresAuth meta flag
  - Verifies authStore.isAuthenticated (token exists + user loaded)
  - Auto-refreshes tokens if expiring within 5 minutes
  - Redirects unauthenticated users to login with return URL

  6. Token Management

  - JWT tokens stored in localStorage
  - Access token included in API requests via axios interceptor
  - Automatic token refresh when approaching expiry
  - Logout clears all auth data and redirects to login

  Common Login Issues to Check:

  1. Backend API connectivity - Check if /api/v1/auth/login endpoint is accessible
  2. CORS configuration - Ensure backend allows frontend origin
  3. Token validation - Verify JWT tokens are properly formatted
  4. localStorage permissions - Check if browser allows local storage
  5. Network errors - Check browser console for failed requests

  The login process is JWT-based with automatic token refresh and persistent sessions via localStorage.
